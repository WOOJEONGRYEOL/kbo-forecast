# 실험 노트 — KBO 단일 경기 예측

한 논문(한국체육학회지 64권 2호, "한국프로야구 경기결과 예측을 위한 머신러닝
성능 비교와 스포츠 팬 몰입 함의…")이 **2013~2023 15,488경기**로 ML을 비교해
**로지스틱 회귀 59.3% 정확도**를 최적 모델로 보고했다. 이를 우리 데이터로
재현하고, **정직한 point-in-time 검증**과 **누수(leakage) 검증**을 대조했다.

실행: `.venv/bin/python experiments/single_game_prediction.py`
(2021~2025 3,158경기, 미래 정보 없이 시점별 피처 구성, 5-fold CV)

## 결과

### 정직한 point-in-time (미래 정보 없음)

| 모델 | 정확도 |
|---|---|
| 무조건 홈 (naive 기저) | 0.514 |
| LR — 피타고리안만 | 0.538 |
| LR — 피타 + 최근폼 | 0.535 |
| **LR — 피타 + 폼 + 선발 K-Stuff** | **0.561** |
| 랜덤포레스트 (전 피처) | 0.554 |

### 누수(leakage) — 시즌 '최종' 집계를 피처로 k-fold

| 피처 | 정확도 |
|---|---|
| 시즌 최종 피타고리안차 | 0.576 |
| 시점별 + 시즌최종 혼합 | **0.588** |

## 인사이트

**1. 단순 모델이 이긴다 (논문 결론 재현).**
랜덤포레스트(0.554) < 로지스틱(0.561). 신호가 적은 데이터에선 복잡한 모델이
노이즈를 학습해 손해. 로지스틱 안에서도 피처가 너무 많으면 떨어졌다
(홈/원정 스플릿 추가 시 하락). 피타고리안 강도차가 지배 신호.

**2. 선발 투수가 팀 강도 다음의 조각 (+2.6%p).**
선발 K-Stuff를 넣자 0.535 → **0.561**. 야구 단일 경기의 최대 변수인 선발이
실재 신호를 낸다. ⚠️ 이는 이 프로젝트의 이전 매치업 백테스트("선발 구위차는
AUC 0.47로 무의미")를 **정정**한다 — 그건 2026 한 시즌(360경기) 노이즈였고,
5시즌 표본에선 작지만 실재하는 기여가 있다. (그래도 56%는 코인플립+α라
'당일 매치업 예측 카드' 미구현 결정 자체는 유효 — 예측력보다 당일 예고 타이밍
문제였으므로.)

**3. 논문 59.3%의 상당 부분은 '누수'일 가능성 (핵심).**
시즌 **최종** 집계(그 팀이 결국 얼마나 좋았나)를 피처로 k-fold 하면
**0.576~0.588**로 논문 수치와 근접한다. 모델이 "어느 팀이 그 시즌 잘했는지"를
미리 알고 중반 경기를 맞추는 셈. 시즌 집계 스탯 + 랜덤 k-fold는 미래를 훔쳐본다
(스포츠 ML 논문의 흔한 함정). **정직한 point-in-time 천장은 ~0.56, '인상적인'
0.59는 검증 세팅에서 나온다.**

## 추가 검증 — 최근가중(EWMA) 투타 성적 (2026-08)

"최근 경기 성적에 투타 가중치를 주면 더 맞지 않나?"를 직접 측정했다. 팀별
경기별 득점·실점을 EWMA(α=0.25, 반감기 ~2.4경기)로 최근 편중해 피처화.

| 피처 | 정직한 시점별 정확도 |
|---|---|
| 기준: 피타+폼+선발 | **0.561** |
| + 최근 타격(득점 EWMA) | 0.561 |
| + 최근 투수(실점 EWMA) | 0.560 |
| + 최근 투타 둘다 | 0.560 |
| + 최근 득실차 EWMA | 0.560 |
| + 순수 핫/콜드 델타(최근−시즌) | 0.561 |
| 최근가중만(시즌 피타 대체) | 0.560 (±0.036, 더 불안정) |

**결론: 최근 결과 가중은 예측력을 못 올린다(오히려 미미하게 ↓·불안정).**
최근 10경기(타자 ~40타석)는 표본이 작아 대부분 운(BABIP)이고, '핫한 방망이'는
지속되지 않아 평균회귀한다. 시즌 피타고리안이 이미 신호를 담고 있어 최근 편중은
노이즈만 더한다. 최근폼(win% form)이 안 도왔던 것(0.538→0.535)과 같은 결이다.

→ **최근성이 정당한 곳은 '결과'가 아니라 (1) 스킬/과정 변화(구속·구위)와
(2) 불펜 피로·가용성(3연투)** — 이건 노이즈가 아니라 실재 신호. 결과 스탯의
최근 편중은 지양.

## 공정한 단서

논문 방법론을 직접 확인하지 못했다. 시간순 분할을 제대로 하고 베팅 배당·정교한
투수 지표 등을 썼다면 정당하게 59.3%에 닿았을 수도 있다. 다만 **우리 데이터로는
정직하게 하면 0.56, 누수를 허용하면 0.59**가 재현된다 — 이 대비 자체가 시사적이다.

## 이 프로젝트에 주는 함의

단일 경기의 정직한 천장이 ~56%(최선을 다해도 44% 오답)라는 것이, 본 프로젝트가
단일 경기 예측을 쫓지 않고 **시즌 순위 확률**(60% 확정 → 스피어만 0.8)·**방향성
회귀 신호**(저평가/고평가·불펜 회귀·ERA-FIP 양극단)·**서술적 분석**(역대·사분면)
으로 우회한 설계를 뒷받침한다.

## 다이내미즘 변수 탐색 (2026-09) — "예측이 단조롭다"에 대한 답

Gemini 레퍼런스("선발 ERA·이닝이 너무 절대적이라 다이내미즘 부족")를 계기로, **정확도와
다이내미즘(예측 스프레드)을 동시에 올릴 변수**가 있는지 네 가지를 point-in-time 백테스트했다.

| 실험 | 가설 | 결과 |
|---|---|---|
| `pitcher_variance.py` | 선발 실점 '변동성'(안전형 vs 폭발형) | ❌ **무효.** 2025 단독은 밴드확대 신호(+0.58) 있었으나 3시즌(1176경기)서 +0.01로 소멸. 투수 분산은 예측·지속 안 됨 |
| `lineup_synergy.py` | 타순 배치·연결성(상위출루×중심장타 등) | ❌ **무시가능.** 평균 대비 개선 MAE ~0.02점/경기, 시즌교차서 뒤집힘. MLB 상식(최적타순 시즌 ~10득점)과 일치 |
| `dips_starter.py` | 선발 '구위'(k_stuff, 운 독립=DIPS)가 생 RA9보다 실점 예측? | ✅ **살아남음.** 이 경기 선발실점과 상관: RA9 +0.039 vs 구위 −0.099. 구위만으로 RA9 이김, 3폴드 재현 |
| `dips_gamelevel.py` | 그 구위 보정을 게임 승부 예측에 반영하면? | 🔶 **정확도만.** 프로덕션(생RA9) 대비 2/3 폴드 Brier·정확도 개선(평균 +1.5%p), 단 공격 반영은 과신(2025). 보수 블렌드(w=0.35)+스케일 유지로 전 폴드 net +Brier |

**핵심 결론(정직):** 단일경기 KBO에선 **"다이내미즘+정확도를 다 잡는 변수"는 원리적으로 없다.**
가장 정확한 신호(DIPS 구위)조차 예측을 **더 모은다**(정확 = 50%쪽 수렴). 넓히면 과신.
→ `game_projection`엔 **DIPS 구위 보정만** 반영(정확도 소폭↑, 다이내미즘은 포기). 상수:
`STUFF_A/B`(구위→기대RA9), `STUFF_W=0.35`(보수 블렌드), `_STUFF_FROM`(소급 방지 게이트).

## 공격 지표·가중 탐색 (2026-09) — "타격을 더 능동적으로 반영해 승부 예측 높이기"

"기대스코어가 투수에 편중된 것 아닌가, 타격/라인업을 더 살리면?"을 검증
(`experiments/offense_metric.py`, point-in-time box_bat·스코어).

- **모델은 이미 대칭**: 기대득점 = lg×구장×공격지수×실점지수×홈보정. 공격·투수 동일 수축(0.85).
  투수가 무거워 *보이는* 건 '오늘 선발'이라 경기마다 흔들리고 공격은 팀 시즌치라 안정적일 뿐.
  (공격은 이미 발표 라인업 wRC+·좌우 플래툰으로 오늘 기준 반영.)
- **공격 가중 민감도**: 0.85가 이미 최적. 1.2↑로 키우면 정확도 하락 → 공격 저평가 아님.
- **공격 지표(RS/G vs OPS)**: 운 벗긴 OPS가 '이 경기 득점' 상관 +0.087 vs RS/G +0.073,
  게임 승부 3폴드 전부 RS/G≥(acc 평균 +~1%p·Brier 중립·**절대 나빠지지 않음**·스프레드 소폭↑).
- **결론**: 실현 개선은 '베이스 공격을 생 RS/G → 운 벗긴 wRC+ 기대득점'으로. game_projection에
  반영(OFF_W=0.5 보수 블렌드 — top-9 wRC+는 팀 OPS보다 스프레드가 커 과신 방지). _OFF_FROM 게이트.
  단일경기 공격은 여전히 near-noise(r~0.08)라 크기는 작다(둘 다 잡는 마법은 없음).
