# 실험 노트 — KBO 단일 경기 예측

한 논문(한국체육학회지 64권 2호, "한국프로야구 경기결과 예측을 위한 머신러닝
성능 비교와 스포츠 팬 몰입 함의…")이 **2013~2023 15,488경기**로 ML을 비교해
**로지스틱 회귀 59.3% 정확도**를 최적 모델로 보고했다. 이를 우리 데이터로
재현하고, **정직한 point-in-time 검증**과 **누수(leakage) 검증**을 대조했다.

실행: `.venv/bin/python experiments/single_game_prediction.py`
(2021~2025 3,158경기, 미래 정보 없이 시점별 피처 구성, 5-fold CV)

## 결과

### 정직한 point-in-time (미래 정보 없음)

| 모델 | 정확도 |
|---|---|
| 무조건 홈 (naive 기저) | 0.514 |
| LR — 피타고리안만 | 0.538 |
| LR — 피타 + 최근폼 | 0.535 |
| **LR — 피타 + 폼 + 선발 K-Stuff** | **0.561** |
| 랜덤포레스트 (전 피처) | 0.554 |

### 누수(leakage) — 시즌 '최종' 집계를 피처로 k-fold

| 피처 | 정확도 |
|---|---|
| 시즌 최종 피타고리안차 | 0.576 |
| 시점별 + 시즌최종 혼합 | **0.588** |

## 인사이트

**1. 단순 모델이 이긴다 (논문 결론 재현).**
랜덤포레스트(0.554) < 로지스틱(0.561). 신호가 적은 데이터에선 복잡한 모델이
노이즈를 학습해 손해. 로지스틱 안에서도 피처가 너무 많으면 떨어졌다
(홈/원정 스플릿 추가 시 하락). 피타고리안 강도차가 지배 신호.

**2. 선발 투수가 팀 강도 다음의 조각 (+2.6%p).**
선발 K-Stuff를 넣자 0.535 → **0.561**. 야구 단일 경기의 최대 변수인 선발이
실재 신호를 낸다. ⚠️ 이는 이 프로젝트의 이전 매치업 백테스트("선발 구위차는
AUC 0.47로 무의미")를 **정정**한다 — 그건 2026 한 시즌(360경기) 노이즈였고,
5시즌 표본에선 작지만 실재하는 기여가 있다. (그래도 56%는 코인플립+α라
'당일 매치업 예측 카드' 미구현 결정 자체는 유효 — 예측력보다 당일 예고 타이밍
문제였으므로.)

**3. 논문 59.3%의 상당 부분은 '누수'일 가능성 (핵심).**
시즌 **최종** 집계(그 팀이 결국 얼마나 좋았나)를 피처로 k-fold 하면
**0.576~0.588**로 논문 수치와 근접한다. 모델이 "어느 팀이 그 시즌 잘했는지"를
미리 알고 중반 경기를 맞추는 셈. 시즌 집계 스탯 + 랜덤 k-fold는 미래를 훔쳐본다
(스포츠 ML 논문의 흔한 함정). **정직한 point-in-time 천장은 ~0.56, '인상적인'
0.59는 검증 세팅에서 나온다.**

## 공정한 단서

논문 방법론을 직접 확인하지 못했다. 시간순 분할을 제대로 하고 베팅 배당·정교한
투수 지표 등을 썼다면 정당하게 59.3%에 닿았을 수도 있다. 다만 **우리 데이터로는
정직하게 하면 0.56, 누수를 허용하면 0.59**가 재현된다 — 이 대비 자체가 시사적이다.

## 이 프로젝트에 주는 함의

단일 경기의 정직한 천장이 ~56%(최선을 다해도 44% 오답)라는 것이, 본 프로젝트가
단일 경기 예측을 쫓지 않고 **시즌 순위 확률**(60% 확정 → 스피어만 0.8)·**방향성
회귀 신호**(저평가/고평가·불펜 회귀·ERA-FIP 양극단)·**서술적 분석**(역대·사분면)
으로 우회한 설계를 뒷받침한다.
